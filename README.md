# New York City Taxi Trip Prediction using Transformer

## Overview

This project focuses on **New York City taxi trip prediction using a Transformer-based Deep Learning model**.

The Transformer model learns patterns from historical taxi trip data and uses the available trip features to make predictions.

The project provides practical experience with **Transformer architecture, data preprocessing, feature engineering, and deep learning for tabular data**.

## Dataset

This project uses the **New York City Taxi Trip** dataset.

The dataset contains information about taxi trips in New York City, including trip-related features that can be processed and used for prediction.

The data is cleaned and prepared before being provided to the Transformer model.
